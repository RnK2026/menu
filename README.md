# RnK · 오늘의 식탁

GitHub Pages에서 동작하는 반응형 식단 안내 사이트입니다. Google Apps Script를 연결하면 관리자 비밀번호로 즉시 식단을 저장할 수 있습니다. 외부 라이브러리 설치는 필요하지 않습니다.

## 기능
- 모스크바 시간 기준 현재/다음 식사 두 개 표시, 1분마다 갱신
- 주간 조식·중식·석식 조회, 이전/다음 주 이동, 인쇄
- 7일 날짜 자동 생성, 셀별 편집, 엑셀 3행 × 7열 붙여넣기 (셀 내부 줄바꿈 지원)
- 브라우저 임시 저장, 미리보기, JSON 백업·가져오기
- 서버 비밀번호 검증, 저장 충돌 감지, 다크 모드
- 메뉴 VoC·숙소 VoC 공개 게시판, 익명 의견 작성, 관리자 답변·삭제

## 1. Google Apps Script 연결 (최초 한 번)
1. https://script.google.com 에서 새 프로젝트를 만듭니다.
2. `apps-script/Code.gs` 내용을 편집기의 Code.gs에 붙여넣습니다.
3. 프로젝트 설정 → 스크립트 속성에 `ADMIN_PASSWORD`를 추가하고 16자 이상의 긴 비밀번호를 직접 설정합니다. 비밀번호를 저장소나 config.json에 넣지 마세요.
4. 편집기에서 `setup` 함수를 선택해 실행하고 Google Drive 권한을 승인합니다. 내 드라이브에 전용 `rnk-meal-data.json` 파일이 만들어지고 파일 ID가 스크립트 속성에 저장됩니다. 재실행해도 기존 파일을 초기화하지 않습니다.
5. 배포 → 새 배포 → 웹 앱: 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 설정하고 배포합니다. 조직 계정 정책으로 익명 웹 앱이 금지되어 있으면 허용되는 계정 또는 다른 백엔드가 필요합니다.
6. `/exec`로 끝나는 웹 앱 URL을 `config.json`의 `apiUrl`에 입력합니다. 관리자 비밀번호는 입력하지 않습니다.
7. config.json을 커밋하고 푸시하면 자동 배포됩니다. 사이트의 메뉴 관리에서 식단 입력 → 비밀번호 입력 → 공개 저장으로 운영합니다.

공개 API는 식단만 읽을 수 있고 저장은 서버 비밀번호 검증을 통과해야 합니다. 원본 Drive 파일은 공개 공유하지 않아도 됩니다. 비밀번호를 웹 브라우저에 저장하지 않으며, 미리보기/임시 저장은 공개 데이터를 수정하지 않습니다. 새 식단은 빈 상태로 시작합니다. 참고 사이트의 실제 식단을 가져오지 않습니다.

코드를 수정한 경우 Apps Script의 배포 관리에서 기존 배포를 새 버전으로 업데이트하세요. 단순 편집기 저장만으로 기존 웹 앱에 반영되지 않습니다. VoC 기능을 추가한 뒤에는 저장소의 최신 `apps-script/Code.gs` 전체를 편집기에 다시 붙여넣고 기존 배포를 새 버전으로 업데이트해야 합니다. 기존 식단 데이터는 유지되며 `voc` 항목은 자동으로 추가됩니다. Google Apps Script/Drive 사용량 제한이 적용됩니다. 인터넷 공개 비밀번호 API이므로 강한 전용 비밀번호를 사용하세요.

VoC 게시글은 모든 방문자에게 공개됩니다. 이름은 비워 두면 `익명`으로 저장되고, 제목 80자·내용 1000자로 제한됩니다. 관리자 답변과 삭제에는 `ADMIN_PASSWORD`가 필요합니다. 첨부파일과 개인정보 입력은 지원하지 않습니다. 반복 등록 방지와 최대 500건 보관이 적용됩니다.

## 2. GitHub Pages 설정
저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다. main 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 정적 파일만 배포합니다.

예상 주소: https://rnk2026.github.io/menu/

Apps Script를 아직 연결하지 않은 경우 data/menu.json을 읽습니다. JSON 백업을 이 파일로 교체하는 정적 운영도 가능합니다. Apps Script 연결 후에는 서버 데이터가 우선합니다.

## 로컬 확인
Node.js 18 이상 및 Python 3 사용:

```sh
npm test
npm run check
npm run dev
```

http://127.0.0.1:4173 에서 확인합니다. file://로 열지 마세요.

식사 시간은 조식 07:30–08:30, 중식 12:30–13:30, 석식 18:30–19:30이며 모스크바 시간을 기준으로 합니다. 주간 메뉴는 월요일부터 일요일까지 표시됩니다. 서버에 예전 시간이 저장되어 있어도 사이트에서 새 시간을 적용하고, 다음 메뉴 저장 시 서버 데이터에도 반영됩니다.

JSON 가져오기는 파일의 첫 날짜부터 7일을 현재 입력표에 불러옵니다. 저장하면 해당 7일만 공개 데이터에 병합하며 다른 날짜는 유지합니다. 동시에 다른 관리자가 저장한 경우 덮어쓰지 않고 새로고침을 요청합니다.
